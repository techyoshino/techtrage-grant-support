# 株式会社テクトレージ - 補助金・助成金の申請サポート HTML統合版

元ページURL: https://www.techtrage.co.jp/service/補助金・助成金の申請サポート/

## ファイル概要

- **`index.html`** (All-in-One 統合版HTML)
  - ヘッダー、ナビゲーション、パンくず、Elementorの全コンテンツ（お悩み・フロー・実績・事例・公募一覧）、CONTACTフォーム、フッターまで、すべてを1つのHTMLファイルに集約しています。
  - WordPressの遅延読み込み（lazyload）プレースホルダー画像を実画像URLに置換済み。
  - ページ固有のElementorスタイル（post-7436.css等）もインライン `<style>` として直接埋め込み、単体で開くだけでオリジナルと全く同一のデザインで閲覧可能です。

## ブラウザでの開き方（Mac）

```bash
open ~/Downloads/index.html
```
